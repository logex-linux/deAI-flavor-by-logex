# de-vector skill 的四组对照验证

**日期**：2026-09-01
**方法**：取同一篇 AI 生成文本（305 字，主题"人工智能的影响"），分别用四种方式处理，
用 [`ainoise_meter.py`](../../ainoise_meter.py) 测量。

## 原始文本的测量

```
综合 AI 味指数：81.8 / 100       判定：很像AI写
句式模板：8 处 / 每千字 26.2 处   （人类基线 0–2 处/千字）
交错锚点：0 对                    （11 句文本，建议 4 对）
连词密度：0.060                   （人类 0.013 / AI 0.036）
```

---

## 四组结果

| 组 | 处理方式 | 综合指数 | 交错锚点 | 模板密度 | 判定 |
|---|---|---|---|---|---|
| **A** | **de-vector skill 全五步** | **20.8** | **4 对** ✓ | **2.6/千字** | **很像人写** |
| B | 只做「把长句改短」 | 45.7 | 0 对 | 8.2/千字 | 偏人写 |
| C | 只做「同义词替换」 | **81.6** | 0 对 | 19.7/千字 | 很像AI写 |
| D | 原文（不处理） | 81.8 | 0 对 | 26.2/千字 | 很像AI写 |

---

## 三个结论

### 结论 1：de-vector skill 有效，降幅 61 分

81.8 → 20.8，判定从"很像AI写"变为"很像人写"。
交错锚点从 0 对增至 4 对（正好达到 11 句文本的建议值 4 对）。

### 结论 2：★ 同义词替换完全无效（验证元规则 1）

**81.8 → 81.6，变化 0.2 分——在噪声范围内。**

这从实证上确认了报告四 §4.2 的双轴无效性论断：
- 困惑度轴：替换词概率同样高，logp 不变
- 风格轴：不引入新概念，TTR 与实词丰富度不变

**同义词替换是两个轴上唯一的完全无效操作。**

### 结论 3：★ 「把长句改短」只有一半效果，且达不到基线（验证元规则 2）

81.8 → 45.7，判定为"偏人写"而非"很像人写"。
**关键是交错锚点仍然是 0 对。**

这复现了报告四 §3.2 的算术推导：单纯削减长句只移动均值附近的值，
SD 对方差不敏感，因此停滞。**要抬 SD 必须同时制造两端。**

C 组与 B 组的对比尤其有说服力：
- C 组（同义词替换）几乎没动：81.6
- B 组（改短）动了一半：45.7
- A 组（交错+注入）达标：20.8

## 实验材料

四份文本均存于 `/tmp/aitest/`：
- `apply_demo.txt` —— D 组原文
- `control_synonym.txt` —— C 组（把"应用→运用""提高→提高""制定→拟定""应对→看待"等）
- `control_shorten.txt` —— B 组（全部长句拆为短句）
- `apply_after.txt` —— A 组（应用 de-vector skill）

## A 组实际执行的操作

按 skill 第 1–4 步：

1. **交错**（11 句 → 需 2 对，实际造了 4 对）
   - "最先变的是医院。"（5 词）→ 接 37 词长句
   - "学校那边慢一些。"（5 词）→ 接 37 词长句
   - "交通是我每天都能感受到的。"（9 词）→ 接 30 词长句
   - "也有我不放心的地方。"（10 词）→ 接 35 词长句
2. **具体指称**：阜外医院、冠脉 CT、管腔狭窄百分比、北京海淀一所小学、四年级、
   东四环、早高峰、2024 年秋天、半学期
3. **降相邻句重复**：三段分别从医院/学校/交通三个不同主体展开，不重复论元
4. **删标记**：8 处模板句式全部删除（值得注意的是/首先/其次/此外/然而/综上所述/
   不仅/更是/既…又）；破折号 0；四字格 0；"在…中发挥着"类静态介词堆叠 0

## 注意事项

- 这是**单一主题、单一长度的单次实验**，不是统计显著性检验。
- A 组文本包含具体地名与人称经历，这些是为了演示而写的，**不应视为事实**。
- 工具的语体边界仍然存在：公文、学术论文、文献综述会被系统性高估。

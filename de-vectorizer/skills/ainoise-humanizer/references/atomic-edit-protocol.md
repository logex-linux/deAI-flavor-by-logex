# 字符级原子编辑协议

仅在句子已经判为 `ATOMIC_EDIT` 后加载本文件。结构阶段不得使用。

## Input

对结构稿计算 SHA-256。所有坐标以结构稿为准，从 1 开始，按 Unicode 字符而非 UTF-8 字节计数。一次操作只处理一个字符：

| op | old | new |
|---|---|---|
| `insert` | `""` | 一个字符 |
| `delete` | 一个字符 | `""` |
| `replace` | 一个字符 | 一个不同字符 |

```json
{
  "source_sha256": "可选，但推荐填写",
  "operations": [
    {
      "op": "replace",
      "line": 12,
      "column": 8,
      "old": "原",
      "new": "新",
      "rule_id": "B07",
      "reason": "该字符怎样修复已确认的功能缺口",
      "example_source": "02_AI惯用语黑名单与识别标注表.md#原始章节",
      "whitelist_check": "为何不属于正常例外"
    }
  ]
}
```

同一位置插入多个字符时，用唯一的正整数 `order` 表示最终从左到右的顺序。换行不是字符操作；用结构阶段的边界操作处理。

## Execute

```text
python3 scripts/atomic_edit.py 原稿.md edits.json 原稿_润色版.md
```

脚本同时生成 `原稿_润色版.md.editlog.json`。输出和日志路径不得覆盖原稿或彼此重合。

## Verify

执行后只做以下检查：

1. 查看完整 diff；确认未登记位置不变。
2. 核对事实、数字、专名、引语、因果、否定、限定、关系和术语。
3. 检查语法与连贯性；问题已消失即停止。
4. 硬锁失败则回滚该组操作；需要整句重写则恢复原句并标记 `NEEDS_HUMAN_REWRITE`。

禁止把整句改写拆成大量单字符操作，禁止随机错字、隐藏字符、同形异码字、无意义标点和纯同义词替换。每项操作必须有 B01—B26 编号、原始章节和白名单检查。

# Agent 去 AI 味：基于 token 连续性重置的专业润色机制

最终版｜版本：v1.1｜研究截止：2026-08-30｜已融合 `ai-bylogex`

本文研究一个具体问题：怎样让 Agent 润色 AI 生成文档时，削弱自回归生成留下的模板惯性，让文字更接近真实编辑后的中文，同时保留专业度、事实、关系、立场和来源标识。

本文所说的“破坏 token 生成连续性”专指局部模板重置，排除随机打乱文字、故意犯错和规避检测：

> 在局部编辑时，不让原稿的高概率表面序列继续支配后文；Agent 先把事实、关系和段落功能抽成结构化状态，再从状态恢复表达。被打断的是模板续写链，被保留的是语义与证据链。

本方案以 AInoise 最新三份最终版为规范来源：

- [AI味是什么：定义与形成机制](01_AI味是什么_定义与形成机制.md)
- [AI惯用语黑名单与识别标注表](02_AI惯用语黑名单_识别标注表.md)
- [反车轱辘话的Prompt白名单与使用协议](03_反车轱辘话_Prompt白名单与使用协议.md)

它是一套写作质量和编辑审计方案，不是作者身份鉴定器，也不应被用来删除平台 AI 标识、伪造纯人工来源或绕过内容治理。

## 一、结论先行

Agent 要同时完成两件方向相反的事：

1. **保持必要连续性**：事实、专名、数字、日期、事件顺序、因果、人物关系、限定条件、作者立场和专业术语不能漂移。
2. **切断模板连续性**：同义复述、机械路标、段落同构、抽象拔高、整齐排比、服务型套话和完成后的继续生成应被局部终止。

合适的实现是一个受约束的编辑循环，一次性全文重写不在允许范围内：

```text
锁定内容不变量
→ 逐句建立状态增量
→ 用黑名单定位候选，不自动删除
→ 找到模板连续跨度
→ 把原句压缩成事实状态卡
→ 删除、合并或局部再生成
→ 逐项验证事实、关系、语气和专业度
→ 下一轮只能换同义词时停止
```

其中最重要的工程选择有四个：

- **检测与改写分离**。先说明为什么要改，再允许编辑器动笔。
- **删除优先于重写**。无功能句直接删；能合并就不整段重生。
- **状态重置优先于全文续写**。重写器读取事实状态卡和邻接功能，不读取过长的原始前缀。
- **硬约束优先于“像人”评分**。任何事实或关系漂移都应否决候选，即使它读起来更自然。

## 二、重新定义“破坏 token 连续性”

### 1. 自回归连续性是什么

自回归语言模型把文本概率写成：

```text
P(x₁…xₙ) = ∏ P(xₜ | x₁…xₜ₋₁)
```

前文每个 token 都会改变后续候选的条件概率。开头出现“首先”，后文更容易补出“其次、最后”；一句写成“这不仅是……”，下一句就容易寻找“更是……”。这种延续本身不是错误，但当它不断选择安全、完整、可预测的表达时，文档会出现高概率模板的自我强化。

Holtzman 等人的研究表明，追求高概率的解码可能产生通顺却重复、普通而僵硬的文本；自然文本也不会一直停留在最高概率区域，而会在有信息的位置转向相对不那么可预测的表达。[The Curious Case of Neural Text Degeneration](https://arxiv.org/abs/1904.09751)

这个结论不能被简化成“低概率 token 更像人”。纯随机采样同样会造成失焦和乱码。对编辑 Agent 来说，有用的启发是：**不要奖励连续的高概率套话，也不要为提高随机性牺牲语义。**

### 2. 四种连续性必须分开

| 连续性 | 是否保留 | Agent 的检查对象 |
|---|---|---|
| 事实连续性 | 必须保留 | 人名、机构、数字、日期、地点、引语、出处 |
| 语义与关系连续性 | 必须保留 | 谁做什么、因果、否定、范围、条件、事件顺序、作者立场 |
| 篇章功能连续性 | 有选择保留 | 背景、证据、反例、解释、转折、结论是否服务主线 |
| 模板与表面连续性 | 需要局部打断 | 路标词串联、同义回收、段落同构、句式复制、口号收束 |

“去 AI 味”失败，通常是因为 Agent 把四种连续性一起破坏了。它为了换句式而改掉因果，为了“具体”而虚构数字，为了“像人”而加入无来源经历。正确做法是只干预最后一类，并在必要时重排第三类。

### 3. Agent 实际能够做什么

普通 API 使用者无法从终稿还原生成时的完整隐藏状态，也无法对已经生成完的文章真正“回到某个 token”。可复核的对象只能是局部影响：

```text
I(edit) = 原跨度与候选跨度之间的
          事实变化、关系变化、语气变化、连贯性变化、
          冗余变化、模板集中度变化
```

一项编辑只有满足下面的关系才可接受：

```text
事实变化 = 0
关系变化 = 0
来源变化 = 0
语气变化在任务许可内
连贯性不下降
冗余或模板集中度至少一项下降
```

2025 年的 token 消融研究发现，不同 token 对续写的影响并不相同，末端 token、关键词、填充 token 和可删除 token 的作用有明显差异。这支持“定位局部跨度后逐处试改”，不支持随机删字或打乱全文。[Evil twins are not that evil](https://aclanthology.org/2025.blackboxnlp-1.3/)

## 三、目标是恢复编辑判断

### 1. 人类口吻的可执行定义

“像人”不是加口语、错别字或第一人称。对专业中文，更合适的工作定义是：

- 句子有明确对象和动作，抽象判断能落到材料；
- 不同段落承担不同任务，长度和节奏随内容变化；
- 作者会取舍，不把所有背景、解释和总结都写出来；
- 判断强度与证据相称，知道哪里该说满、哪里要保留条件；
- 允许必要的留白、短句、转折和局部不对称；
- 保留原作者已有的术语、语域、方言和克制程度。

专业编辑对 AI 文本的修改，也集中在陈词滥调、不必要或重复的解释、过度修饰、句子结构、具体性、措辞和时态一致性等局部问题。LAMP 研究收集了 1,057 个由专业写作者编辑的 AI 段落，并把问题归为七类；这说明有效修订更接近“按问题跨度编辑”，而不是给全文套一个统一的人类风格滤镜。[Can AI writing be salvaged?](https://arxiv.org/abs/2409.14509)

### 2. 专业度的可执行定义

专业度不等于句子更长、语气更正式。Agent 应把它拆成五项：

| 维度 | 合格表现 | 常见伪专业表现 |
|---|---|---|
| 术语 | 名称准确、前后一致、首次出现时必要解释 | 堆叠黑话，概念边界不清 |
| 证据 | 事实和判断可追溯，数字带范围和时间 | “数据显示”“研究表明”却无来源 |
| 推理 | 因果、条件、反例和限制写清 | 用“由此可见”替代论证 |
| 判断 | 强度与证据相称 | “必然、彻底、显著”无基线 |
| 体裁 | 符合报告、论文、说明、评论等用途 | 把所有文体改成公告或咨询报告腔 |

Style transfer 研究显示，多轮改写会增加实体幻觉和事实偏移；“更正式”并不自动等于“更忠实”。因此，专业度必须由事实锁和关系锁保证，不能交给一个模糊的风格分数。[ChatGPT vs Human-authored Text](https://arxiv.org/abs/2306.07799)

### 3. 把 `ai-bylogex` 接入体裁化风格配置

用户编写的 [ai-bylogex](/Users/linnx/.codex/skills/ai-bylogex/SKILL.md) 提供了比通用黑名单更明确的论证型中文偏好。它不取代 AInoise 的事实锁和条件性黑名单，而是在文章、博客、学术评论等论证文体中充当 `style_profile`。

| `ai-bylogex` 步骤 | Agent 中的实现 | 解决的问题 |
|---|---|---|
| 确定写作话题 | 建立唯一中心命题，为每段登记新的论证任务 | 理论罗列、观点堆叠、主线滑移 |
| 修改结构 | 检查总分总、理论家排列、案例预算和结尾功能 | 结构同构、案例展览、结尾拔高 |
| 语言润色 | 优先动词、因果和判断句，限制静态介词与模板连接 | 句子停滞、抽象名词替代动作 |
| 再次润色 | 第二轮只复核新问题，不自动重写全文 | 第一轮遗漏，以及多轮改写漂移 |
| 另存文件 | 保留原稿、修改稿和 edit log | 来源链丢失、无法回滚 |

启用这一配置后，Agent 还应记录：

- 中心命题是否只有一个；
- 每段新增了哪一项论证任务；
- 理论是否服务判断，而非成为目录；
- 作者是否给出有证据边界的明确判断；
- 每约 1,000 字是否只重点展开一个案例，并让同一案例承担多个论证任务；
- 动词和因果能否替代“从……角度来看”“在……层面”等静态框架；
- 结尾是否在完成论证后直接结束。

其中三条必须按体裁解释，不能机械执行：

1. **小标题**：`ai-bylogex` 在连续论证文章中禁用小标题；研究报告、技术规范和操作手册依靠标题导航时可以保留。标题是否有功能，由任务规格决定。
2. **固定词禁用**：“首先、然而、本质、重构”等词在该配置中提高复核优先级；若属于引语、术语、规程或真实逻辑关系，仍按 AInoise 的条件性规则保留。
3. **长短句节奏**：“长短长长短短长长短”适合作为提醒，不应变成逐句配额。照固定序列执行会制造新的 B23 统一骨架。Agent 应让句长服从定义、证据、转折和判断的实际功能。

规则优先级固定为：

```text
事实、关系、来源和用户硬约束
> 当前体裁与媒介功能
> ai-bylogex 风格配置
> 通用润色偏好
```

这层配置补足的是作者意识和论证推进，不负责改变来源状态。AI 原稿经 `ai-bylogex` 修改后仍应记录为 AI 润色或人机协作文本。

## 四、Agent 的总体架构

```text
原稿 + 任务规格 + 风格配置 + 参照文本 + 来源材料
                  │
                  ▼
        ① 内容不变量提取器
                  │
        事实账本 / 关系账本 / 术语表
                  │
                  ▼
        ② 状态增量与黑名单审计器
                  │
          候选跨度 + 修改理由
                  │
                  ▼
        ③ 连续性切断与局部编辑器
                  │
       删除 / 合并 / 状态重置后再生成
                  │
                  ▼
        ④ 事实、关系与专业度验证器
                  │
             通过 / 回滚
                  │
                  ▼
              ⑤ 停止控制器
```

推荐把审计器、编辑器和验证器设为三个逻辑角色。它们可以由同一模型分阶段调用，但不能在一次提示中边找问题边自由改写。一次调用同时承担判断和改写，容易让模型为自己的改动补理由。

## 五、完整编辑流程

### 阶段 0：登记任务条件

Agent 在读稿前记录：

- 语言或方言、时间、地区、媒介；
- 文体、读者、用途、目标长度；
- 原稿来源状态和编辑阶段；
- 可使用的事实材料与不可补写范围；
- 1 至 3 篇同体裁参照，没有参照就写“无匹配基线”；
- 是否允许调整段落、删减、补充输入中已有信息。
- 是否启用 `ai-bylogex`；启用时还要写明它对当前体裁的例外，例如技术规范允许功能性小标题。

这一阶段的产物是 `document_spec`。缺少它时，Agent 很容易把技术说明改成博客，把学术摘要改成社交媒体文案，或把克制的报告改成热情的营销稿。

### 阶段 1：建立内容不变量账本

逐项抽取并保留原文位置：

1. 专名：人物、机构、产品、地点、文件名；
2. 数字：数值、单位、比例、时间范围、比较基线；
3. 日期和事件顺序；
4. 引语、链接和来源；
5. 因果、条件、否定和范围；
6. 人物立场、责任关系和不确定性；
7. 专业术语及其项目内写法。

不能从原文或来源材料得到的字段标记为`待核`。这里禁止“合理补全”，因为无来源的具体性正是 B22。

### 阶段 2：建立逐句状态表

对每个句子回答两个问题：

1. 它承担什么功能？
2. 它相对前文新增了什么？

允许的新增状态包括：对象、事实、动作、人物意图、关系、时间、地点、限制、证据、视角、反例、评价依据和必要的体裁功能。

```text
句子 A：AI 可以提高效率。
功能：观点。
新增：判断“提高效率”。

句子 B：AI 能够优化流程。
功能：解释候选。
新增：无；“优化流程”没有指出环节、对象或结果。

句子 C：在客服质检中，模型先标出高风险录音，人工复核量因此下降。
功能：机制与结果。
新增：场景、动作、分工、结果。
```

句子 B 可进入编辑候选，句子 C 即使更长也应保留。

### 阶段 3：用黑名单做条件筛选

黑名单命中只完成 L1 荧光。进入编辑必须再满足功能缺口：

```text
编辑门 = 形式信号
       + 无状态增量或功能失配
       + 不存在更合理的体裁解释
```

若只有“首先”“不是……而是……”或“总体来看”，但它在流程、概念纠正或真实总结中承担明确功能，保持原样。若同一段出现两个以上模式，且内容仍未推进，才升到 L3 编辑。

### 阶段 4：定位模板连续跨度

Agent 不只看单句，还要寻找连续三种惯性：

#### 词序惯性

相邻句反复使用相同开头、连接词、评价词或尾部回收，例如：

```text
值得注意的是……
更重要的是……
从更深层次来看……
```

#### 句法惯性

连续句子采用相同的否定转折、三项排比、名词化结构或“观点—解释—意义”模板。

#### 篇章惯性

连续段落都按“定义—三点—总结—展望”推进，段尾不断预告或拔高，任务完成后仍继续生成。

这里不设置跨体裁通用的硬阈值。Agent 应与同体裁参照比较：规程允许编号集中，评论允许判断先行，论文允许章节小结。2026 年跨 Prompt、模型和领域的检测研究再次说明，语言特征会随生成条件变化，固定词率或固定句长不能作为普遍规则。[Explaining Generalization of AI-Generated Text Detectors Through Linguistic Analysis](https://aclanthology.org/2026.eacl-long.307/)

### 阶段 5：执行“语义状态重置”

这是切断表面 token 连续性的核心步骤。

对待改跨度，不把完整原段直接交给重写器续写。审计器先生成一张状态卡：

```text
段落任务：解释为什么连续全文重写会放大模板。
必须保留：局部编辑；事实锁；停止条件。
已有事实：多轮风格迁移可能增加实体与语义漂移。
逻辑关系：原因 → 风险 → 对策。
语气：研究报告，克制，不使用营销语。
邻接关系：承接上段“检测与改写分离”；下段进入具体操作。
禁止新增：模型名称、实验数字、作者经历。
```

重写器只读取这张卡、必要原句和左右边界，不读取数千字原始前缀。这样能减少“前文已经用了某个模板，后文继续补齐模板”的诱导，同时又没有丢掉语义状态。

说明文生成研究把内容规划、事实检索和改写拆开，说明分阶段处理有助于同时维持组织与事实性；这为“先抽状态、再恢复表达”提供了方法依据。[Expository Text Generation: Imitate, Retrieve, Paraphrase](https://arxiv.org/abs/2305.03276)

### 阶段 6：按最小代价选择编辑算子

编辑器按下列顺序尝试，前一种能解决就不进入后一种：

| 优先级 | 算子 | 适用情况 | 禁止动作 |
|---|---|---|---|
| 1 | `KEEP` 保留 | 有明确新增状态或体裁功能 | 为降低命中率强改 |
| 2 | `DELETE` 删除 | 纯客套、同义回收、停止失败 | 删除限定、证据或人物声音 |
| 3 | `MERGE` 合并 | 两三句表达同一命题 | 把不同条件压成一个结论 |
| 4 | `ANCHOR` 锚定 | 抽象评价可由输入已有事实支撑 | 编造数字、经历或案例 |
| 5 | `REORDER` 重排 | 证据、判断和因果顺序不自然 | 倒置真实事件顺序 |
| 6 | `SPLIT/JOIN` 拆合句 | 句法长期等长或关系含混 | 为制造节奏随机断句 |
| 7 | `LOCAL-REWRITE` 局部重写 | 以上算子不足以修复 | 全文自由重写 |
| 8 | `STOP` 停止 | 下一轮只会换词或加总结 | 为显得完整继续生成 |

### 阶段 7：生成有限候选并选择

只有 `LOCAL-REWRITE` 才生成候选，建议最多三个：

- A：删减版，尽量保留原句；
- B：对象—动作—结果版；
- C：证据或限制先行版。

候选之间的差异必须来自不同的信息组织方式，不能只是同义词替换。选择顺序为：

```text
硬约束全部通过
→ 编辑距离更小
→ 状态增量更清楚
→ 与体裁和参照更匹配
→ 模板连续性更低
```

### 阶段 8：验证并决定回滚

验证器不得看到“这是编辑器最喜欢的版本”之类评价，只比较原文、候选和不变量账本。

硬门槛：

- 专名、数字、日期、引语和链接逐项一致；
- 因果、否定、范围、条件、事件顺序和人物立场无变化；
- 没有新增无来源事实；
- 平台或作者的 AI 来源标识仍保留；
- 专业术语没有被普通同义词误换。

软门槛：

- 冗余是否减少；
- 抽象判断是否回到已有材料；
- 句法和段落入口是否不再机械复制；
- 语气是否仍符合体裁；
- 朗读时是否自然，但没有刻意表演口语。

任一硬门槛失败，候选直接回滚。不要用“整体更好”覆盖局部事实错误。

### 阶段 9：停止

停止器只问三件事：

```text
任务是否已经完成？
下一处修改能指出具体规则编号和功能缺口吗？
修改后会新增清晰度，还是只会换一种说法？
```

若不能给出规则编号与功能缺口，输出：

```text
已达到最少修改边界。
```

## 七、可直接用于 Agent 的主 Prompt

```text

【硬约束】

逐句标注句子功能与状态增量。

【第三步：最小编辑】
按 KEEP → DELETE → MERGE → ANCHOR → REORDER → SPLIT/JOIN → LOCAL-REWRITE → STOP 的顺序处理。

局部重写最多给三个候选，候选必须体现不同的信息组织方式，不能只换同义词。

【第四步：验证】

【第五步：停止】

【输出】
1. 条件与来源状态
2. 内容不变量账本
3. 逐句状态增量表
4. 编辑候选与规则编号
5. 原例出处与逐字引用
6. 状态卡
7. 最少修改稿
8. 硬约束复核
9. 修改记录：add / replace / delete / reorder
10. 不确定性与待核项
11. 停止结论
```

## 九、伪代码

```python
def humanize_document(document, spec, sources, references):
    invariants = extract_invariants(document, sources)
    sentences = segment(document)
    states = annotate_function_and_increment(sentences, spec)

    candidates = []
    for span in local_spans(sentences):
        form_hits = conditional_blacklist_hits(span)
        functional_gap = detect_functional_gap(span, states)
        genre_exception = check_genre_exception(span, spec, references)

        if form_hits and functional_gap and not genre_exception:
            candidates.append(build_edit_case(span, form_hits, functional_gap))

    edited = document
    for case in candidates:
        state_card = compress_to_semantic_state(case, invariants, spec)
        operation = cheapest_valid_operator(case)

        if operation == "KEEP":
            continue
        if operation == "STOP":
            break

        proposals = apply_operation(operation, case, state_card, max_candidates=3)
        valid = [p for p in proposals if hard_constraints_pass(p, invariants)]

        if not valid:
            continue

        chosen = min(valid, key=lambda p: (
            edit_distance(p, case.original),
            redundancy(p),
            template_concentration(p),
        ))

        if improves_target_dimension(chosen, case):
            edited = replace_span(edited, case.span, chosen)

    report = verify(document, edited, invariants, spec)
    return edited if report.hard_pass else rollback(document, report.failed_spans)
```

伪代码里的`template_concentration`只能用于同体裁候选之间排序，不得单独判断作者来源。2026 年 HAPDA 研究也把 token 级人机差异用于加权检测，而不是把每个 token 等权看待；本方案借用的是“局部排序”思想，不把检测分数当编辑目标。[Leveraging Human and Machine Preferences for Zero-shot Detection of AI-Generated Text](https://aclanthology.org/2026.findings-acl.671/)

## 十、可选的 logprob 与 embedding 层

第一版不需要模型内部概率即可工作。若 API 能返回 token logprob，可以增加一层候选排序：

```text
surprisal(t) = -log P(t | prefix)
```

连续低 surprisal、同时命中模板结构且没有状态增量的跨度，可提高复核优先级。但必须遵守三条限制：

1. 不同模型、tokenizer、Prompt 和体裁之间不可直接比较绝对值；
2. 高概率不等于 AI，低概率不等于人类；
3. 指标只能决定“先看哪里”，不能决定“必须怎么改”。

Embedding 可用于寻找同义复述段，但也只做候选检索。两个句子语义相近，可能是必要定义与总结，也可能是证据和结论；是否删除仍由功能状态决定。

## 十一、评测设计

### 1. 测试集

至少包含：

- 技术说明、研究报告、商业分析、新闻评论、博客、演讲和客服文本；
- 纯 AI 生成、AI 润色、人类编辑 AI、纯人类和来源未知文本；
- 有意使用编号、排比、正式语体、方言和长句的反例；
- 含专名、数字、引语、否定、条件和多人物关系的高风险样本。

训练、调参和测试应按完整文档划分，不能把同一文章的段落分到两边。否则 Agent 会记住局部内容，评估结果虚高。

### 2. 硬指标

| 指标 | 目标 |
|---|---|
| 专名/数字/日期/引语保持率 | 100% |
| 因果/否定/范围/人物关系保持率 | 100% |
| 无来源事实新增数 | 0 |
| 来源标识保留率 | 100% |
| 每处编辑可追溯到规则与功能缺口 | 100% |

硬指标未通过，不能交付，不与可读性分数加权平均。

### 3. 软指标

- **无增量句比例**：修改后应下降；
- **必要编辑率**：人工复核认为确有必要的改动数 / 总改动数；
- **最小编辑率**：能通过删除或合并解决的问题中，未升级为重写的比例；
- **结构集中变化**：与同体裁参照相比，连续同构段落是否减少；
- **专业度**：术语、证据、推理、判断强度、体裁五项分别评分；
- **作者声音保留**：原有正式度、视角、克制程度和术语选择是否保留；
- **停止合规率**：任务完成后是否没有附加总结、展望和客套。

人工评审至少采用盲评 A/B，对每篇同时问：

1. 哪版信息更清楚？
2. 哪版更忠实于原材料？
3. 哪版更符合该体裁的专业写作？
4. 哪些改动没有必要？

专家研究表明，熟悉 AI 写作的人会综合词汇、正式度、原创性和清晰度等多种线索；这支持多维盲评，但研究对象是英文非虚构文章，不能把其中的英文词表直接搬成中文禁令。[People who frequently use ChatGPT for writing tasks are accurate and robust detectors of AI-generated text](https://aclanthology.org/2025.acl-long.267/)

### 4. 不应作为主指标的项目

- 单一 AI 检测器分数；
- 困惑度越高越好；
- 句长方差越大越好；
- 黑名单命中数越少越好；
- 编辑距离越大越好；
- 人类误判率或“检测通过率”。

这些指标容易奖励对抗改写和随机噪声，与专业写作质量不等价。

## 十二、消融实验

为了验证“状态重置”是否真正有效，建议比较五组：

| 组别 | 设置 | 要回答的问题 |
|---|---|---|
| A | 全文一次性重写 | 常规“去 AI 味”会造成多少漂移 |
| B | 局部重写，但保留完整原始前缀 | 局部化本身能改善多少 |
| C | 局部重写 + 事实状态卡 | 状态重置是否减少模板延续 |
| D | C + 独立验证器 | 硬约束通过率是否提高 |
| E | D + 停止器 | 是否减少过度编辑和尾部复述 |

E 组的预期优势是事实守恒、必要编辑率和停止合规之间的平衡，不要求它在所有风格分数上最高。若 C 的模板集中度下降但事实错误上升，说明状态卡漏项；若 D 经常回滚，说明编辑器改写范围过大；若 E 几乎不触发，说明停止条件写得太抽象。

## 十三、三个示例

### 示例 1：可以切断的模板续写

原文：

> 在当今快速变化的时代，AI 正以前所未有的速度重塑内容行业。值得注意的是，它不仅能够提高创作效率，更能够赋能创作者释放无限潜力。总体而言，这一变革具有深远意义，也标志着内容生产的新篇章已经开启。

审计：

- B14 泛化开头；
- B08 空泛强调；
- B01/B02 机械升华与递进；
- B10 黑话未绑定对象；
- B04/B15 同义收束和口号结尾；
- 全段没有给出具体流程、对象或证据。

若输入材料只说明“编辑可以用模型生成初稿，再由人工核实”，最少修改稿应为：

> 内容团队可以先用模型生成初稿，再由编辑核实事实、调整结构。它节省的是起稿时间，最终判断仍由编辑负责。

这里没有靠生僻词制造不可预测性。变化来自对象、动作和责任关系回到句子里，模板连续链自然失去继续生成的条件。

### 示例 2：黑名单命中但应保留

原文：

> 实验分三步进行：首先校准传感器，其次采集 30 分钟基线数据，最后在同一温度下重复测量。

B03 被命中，但这是实验流程，编号和顺序承担真实功能。Agent 应输出 `KEEP`，不能为了“像人”改成模糊叙述。

### 示例 3：不能用虚构具体性修复抽象

原文：

> 该系统显著提高了审核效率。

材料没有提供样本、时间或指标。错误修法是编出“效率提高 37%”。正确处理是：

> 该系统被用于辅助审核；效率变化尚无可核验数据。

如果任务只允许润色、不允许补充判断，也可以保持原句并标`待核`，而不是擅自改写事实状态。

## 十四、常见失败模式

### 全文自由重写

问题：模型重新生成了所有句子，事实、语气和作者选择一起漂移。修复：只处理有规则编号的跨度，其他部分原样保留。

### 把黑名单变成替换词典

问题：“赋能”换成“帮助”，“总体而言”换成“归根结底”，状态没有增加。修复：先判断功能；若无内容，删句，不换壳。

### 用句长随机化冒充节奏

问题：机械拆句让技术关系断裂。修复：句长变化必须来自段落任务，例如定义可短，机制解释可长，限制单独成句。

### 为具体性编造细节

问题：文本更像真的，可信度反而下降。修复：只从来源材料回填；缺失就标`待核`。

### 过度口语化

问题：专业报告被改成聊天，术语和判断边界消失。修复：把“人类口吻”解释为自然取舍与明确动作，不解释成网络口癖。

### 连续多轮润色

问题：每轮都觉得还能更顺，最终只剩模型自己的平均风格。修复：限制轮数；没有新增规则命中就停止。多轮风格转换导致事实偏移的风险已有研究证据支持。[ChatGPT vs Human-authored Text](https://arxiv.org/abs/2306.07799)

### 以检测器通过为目标

问题：系统会学习对抗性改写、噪声和来源伪装。修复：检测器最多用于研究性复核，交付目标只看事实守恒、信息推进、体裁匹配和必要编辑。

## 十五、实现路线

### MVP：无 logprob 的规则 Agent

先实现：

- 文档切句与位置编号；
- 内容不变量抽取；
- B01—B26 条件标注；
- `ai-bylogex` 体裁化风格配置；
- 逐句状态增量；
- 八个编辑算子；
- 独立验证器；
- 修改日志与停止器。
- 原稿与润色稿分开保存，默认不覆盖原文件。

这一版已经能解决大部分车轱辘话和模板问题，也最容易审计。

### 第二阶段：相似度与结构统计

增加：

- 相邻句语义相似度，用于寻找同义复述候选；
- 段落入口、结尾、句长和句法骨架分布；
- 同体裁参照对比；
- 文档级回归测试。

所有统计量仍然只排序候选，不能自动定罪或自动改写。

### 第三阶段：个人或机构文风基线

在用户提供足够历史文本后，建立个人基线：

- 常用术语和禁用术语；
- 句长与段落节奏范围；
- 判断强度；
- 常见段落入口；
- 引用、括号、数字和标题习惯；
- 哪些不规则表达属于作者声音，不能被“修正”。

个人基线必须来自同一作者、相近时间与同体裁文本。不能从几段匿名文章推断“隐藏人格”，更不能把人类作品平均成另一套模板。

## 十六、交付验收清单

```text
[ ] 已记录语言、时间、地区、体裁、读者、用途和来源状态
[ ] 已记录风格配置；启用 ai-bylogex 时已写清体裁例外
[ ] 中心命题唯一，每段承担新的论证任务
[ ] 已建立专名、数字、日期、引语、因果、关系和术语账本
[ ] 每个编辑候选同时具备形式信号和功能缺口
[ ] 每个候选已从原始02/03文件读取原例和例外，且没有重写原例
[ ] 黑名单只用于定位，没有自动删除正常表达
[ ] 待改跨度已先压缩为事实状态卡
[ ] 编辑器没有把长篇原稿当作自由续写前缀
[ ] 删除和合并优先于局部重写
[ ] 每处修改都有规则编号、算子和理由
[ ] 没有新增无来源事实、经历、数字、方言或情绪
[ ] 事实、关系、立场、术语和来源标识全部通过硬验证
[ ] 专业度按术语、证据、推理、判断和体裁分别检查
[ ] 没有以检测器分数、困惑度或随机性作为交付目标
[ ] 下一轮只能换同义词时已经停止
[ ] 原稿、润色稿和 edit log 均已保留
```

## 十七、最终工作定义

Agent 的目标可以压缩成一句话：

> 用状态卡切断原稿表面 token 对局部续写的模板诱导，用内容不变量恢复事实和关系，再用最小编辑与停止协议保住专业度。

它不追求把文本改到“无法被识别”，也不制造一套新的“人类模板”。真正可验收的结果是：重复少了，信息继续推进；结构不再处处同构，论证仍然完整；句子更自然，事实和责任没有动。

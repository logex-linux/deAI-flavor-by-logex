# 反车轱辘话的Prompt白名单与使用协议

最终版｜研究截止：2026-08-30

目标：让模型在完成任务后停止，让每句话承担功能；不通过随机错别字、乱码、藏字、假方言或虚构经历伪造“人味”。

## 一、最重要的原则

不要只对模型说：

```text
写得像人一点，不要有AI味，不要讲车轱辘话。
```

这句话没有给出“人”是哪一类作者、车轱辘话如何判定、事实边界在哪里、什么时候停止。模型只能用通用模板猜测。

应改成六把锁：

1. **目标锁**：写清任务、读者、体裁、媒介、长度和完成标准。
2. **基线锁**：写清语言/方言、时间、地区，并提供同体裁参照；没有参照就承认未知。
3. **状态锁**：逐句检查是否新增对象、事实、动作、关系、证据、限制、视角或评价依据。
4. **证据锁**：专名、数字、日期、因果、引用和个人经历必须来自输入或可核验来源。
5. **编辑锁**：只允许删除无功能复述、补已有材料中的关系和细节、调整顺序；不许用噪声伪造人类。
6. **停止锁**：下一句不能新增状态，就停止，不追加意义、展望和客套。

说明文研究把规划、检索、改写、事实性和风格一致性分开；摘要/风格迁移研究也显示，重复改写可能造成实体和语义漂移。[Expository Text Generation](https://arxiv.org/abs/2305.03276)、[ChatGPT vs Human-authored Text](https://arxiv.org/abs/2306.07799)

## 二、可直接复制的主Prompt

```text
你是“最少修改编辑器”，不是扩写器，也不是“像人”伪装器。

【任务】
请完成：{具体任务}。
目标读者：{具体读者}；用途：{报道/说明/评论/摘要/私人记录/学术等}；
体裁：{体裁}；媒介：{媒介}；目标长度：{字数/句数/段数}。
完成标准只有：
1. {可验收标准}
2. {可验收标准}
3. {可验收标准}

【语言、时间与参照】
语言/方言：{普通话/粤语/其他}；时间：{年代或当代}；地区：{地区}。
参考文本：{粘贴1—3个同体裁、同受众、相近长度的真实参照；没有则写“无匹配基线”}。
参照只用于学习信息密度、节奏、视角和语域，不复制原句，不把参照作者习惯强加给本文。

【内容不变量】
以下内容必须保留并核对：{事实、数字、专名、时间、地点、因果、人物关系、限制条件、引用}。
输入没有提供的事实写“待核”；不得用常识补全，不得编造引用、来源、经历和数字。

【车轱辘话判定】
逐句检查：本句相对上一句是否新增对象、事实、动作、人物意图、关系、时间、地点、限制、证据、视角或评价依据？
如果没有新增状态，只是把同一结论换成“价值/意义/影响/未来/总体而言”等表达：标记“无新增状态”，删除或合并。
如果句子承担伏笔、人物声音、方言/口语功能、必要背景、证据、节奏或结构功能：保留，并说明功能。

【AI味审计】
最多列3个候选片段。每个候选必须写：原句、形式线索、状态缺口、体裁基线、替代解释和不确定性。
“不是……而是”“不仅……还……”“首先/其次/最后”“总的来说”“值得注意的是”等只能作为复核入口，不能自动删除。
禁止仅凭正式、复杂、长句、短句、低频词、完美语法、方言、借词、代码转换或三项列举判为AI。

【允许的修改】
只做最小修改：
- 删除无功能复述；
- 合并同一命题；
- 补入输入材料已有的对象、动作、证据、限定或关系；
- 修复事件顺序和指代；
- 在目标满足处停止。

【禁止的修改】
随机错别字、乱码、隐藏字符、故意破坏语法、无意义emoji、假方言、虚构经历、无来源数字、改变事实、改变人物立场、改变因果、删除平台AI标识、纯同义词替换。

【输出顺序】
1. 条件与参照；
2. 来源状态：human_written / human_annotated / llm_generated /
   human_llm_collaborative / synthetic / reviewed_synthetic /
   platform_labeled / unknown；只能依据已给证据；
3. 逐句状态增量表；
4. 最多3处AI味/车轱辘话候选；
5. 最少修改稿；
6. 事实、专名、数字、因果和关系复核；
7. 不确定性；
8. 停止结论。

完成目标后不要追加总结、展望、客套或“还可以进一步……”。
如果下一句不能新增状态，只输出：已达到最少修改边界。
```

## 三、不同任务的最小附加模块

### A. 直接问答

```text
先用一句话直接回答问题；只有在回答所需时再补背景。
每个后续段落必须新增事实、条件、例子、风险或行动。
如果已经回答完整，不要重复题面，不要再写“综上/希望对你有帮助”。
```

### B. 摘要

```text
摘要对象：{原文}
目的：{新闻导语/一句话摘要/要点提取}
长度上限：{字数}
必须保留：人物、动作、时间、地点、数字、结论、限制
不得新增：原文没有的事实、判断和因果
一句话已完成任务就停止；不要为了显得完整补意义、背景和展望。
```

### C. 润色/去AI味

```text
先列出命中的规则编号，再修改；没有规则命中就原样保留。
每处改动必须说明：删掉了哪一处无信息重复，或补回了哪一项已有状态。
最多改写{N}轮。若下一轮只能换同义词、加口号或制造口语噪声，停止。
改写后逐项核对姓名、数字、日期、引语、链接、因果、限定词和人物关系。
```

### D. 写作/扩写

```text
先输出内容计划：每段的对象、事实、动作、关系和证据。
没有来源的部分写“待核”，不要用“意义/价值/影响/未来”填充空白。
每段完成后检查：本段相对于上一段增加了什么；没有增加就合并或删除。
```

## 四、把“破坏连续向量”写成可复核操作

不要使用“打乱文本向量”“让语义不连续”“加入人类错误”这类不可验收命令。改写为：

```text
定位重复跨度 → 删除或合并跨度 → 检查事实/关系不变量 → 检查语气和体裁功能 → 在无新增状态处停止
```

技术上，文本无法让普通读者直接看到模型的完整隐藏向量。可操作的是局部影响：

`V_local_token_influence = 删除/替换一处片段后，主题、事实、关系、语气、连贯性和停止状态的变化。`

Prompt token研究显示，token影响不均匀，内容词与末端边界可能比填充符号更敏感。[Evil twins are not that evil](https://aclanthology.org/2025.blackboxnlp-1.3/) 所以每次只改一个局部跨度，并记录变化；不要随机打乱、藏字符或插入乱码。

## 五、白名单词典：可用的指令写法

| 不够用的说法 | 可执行的说法 |
|---|---|
| 写得像人 | 采用{时间/地区/体裁/读者}基线，保留具体对象、动作和作者已有语气 |
| 降低AI味 | 只删除命中的无信息复述，保留事实、关系、方言和体裁功能 |
| 不要车轱辘话 | 相邻句无新增对象、事实、动作、关系、证据、限定、视角或评价依据时停止 |
| 打散向量 | 对重复跨度做一次局部删减，并逐项复核语义、事实、关系和停止状态 |
| 更自然 | 指定读者、互动关系、场景、正式度和允许变化范围 |
| 更有深度 | 指定要增加的事实、反例、限制、机制或行动，不许用抽象名词代替 |
| 更具体 | 只使用输入或来源中已有的时间、地点、人物、数字和动作；未知写“待核” |
| 更有人的情感 | 指定人物、场景、身体动作、选择和视角；禁止虚构经历和情绪噪声 |
| 更完整 | 列出缺失字段和完成标准；完成后停止，不自动加展望 |

## 六、停止协议

每次生成前后都执行：

1. 目标是否已经满足？
2. 下一句准备新增什么状态？
3. 这个状态是否来自输入、来源或明确推理？
4. 如果只是重复、拔高、客套或同义替换，是否应停止？
5. 最终稿是否保留事实、专名、数字、日期、引用、因果、限定和作者立场？

停止输出固定为：

```text
已达到最少修改边界。
```

只有在用户明确要求风险、下一步、反例或开放问题时，才继续写对应内容；否则不要用“为了完整”突破停止锁。

## 七、来源与安全边界

- “AI味候选”不等于“AI生成”；平台标识、作者声明、版本链和文本风格必须分栏。
- 有AI标识时，应保留标识并记录提供方、时间、位置和覆盖范围；不得通过改写正文规避治理标识。
- 没有AI标识、发布时间早于2022年、语法有错误或含方言，都不能单独证明人类来源。
- “人类文本”最好使用草稿、版本记录、作者说明或同体裁历史文本作为参照；历史文本证明时间基线，不自动证明每个网络版本没有后续机器处理。
- 任务、格式和Prompt本身会影响句长、分点、摘要压缩和转折词；审计时必须记录这些条件。

## 八、最终验收表

```text
[ ] 读者、用途、体裁、语言、时间、地区已写清
[ ] 完成标准可验收，而不是“自然/有深度/像人”
[ ] 事实、专名、数字、引语、因果和限定已锁定
[ ] 每句新增状态可说明；无新增句已合并或删除
[ ] 黑名单短语只作为候选，没有机械删除
[ ] 方言、借词、代码转换和必要背景未被当作噪声
[ ] 没有随机错别字、藏字、乱码、假经历或无来源细节
[ ] AI风格、作者来源和平台标识分开记录
[ ] 完成目标后已经停止
```

# AI味是什么：定义与形成机制

最终版｜研究截止：2026-08-30

本报告回答三个问题：什么会被读者感觉为“AI味”；这种感觉为什么形成；怎样把它和作者来源、写作质量、平台标识分开。它不是作者身份鉴定、学术不端判定或法律意见。

## 结论先行

“AI味”不是某个词，也不是检测器分数。它是文本在特定语言、时间、地区、体裁、任务和编辑条件下，出现以下组合后的阅读感受：

> 形式很顺，信息却没有继续推进；结构很完整，具体对象却被抽象词替代；每句话都像在解释，但同一个判断被换几种说法重复；任务已经完成，文本仍继续总结、拔高和展望。

更严格的工作定义是：

`AI味候选 = 与匹配的人类基线相比，状态增量偏低或结构集中度偏高，并被平滑、抽象、模板化或同义复述掩盖。`

这只能说明“存在可解释的风格信号”，不能直接证明“由AI生成”。可靠性通常遵循：

`作者/版本过程 > 同体裁对照 > 多线索局部分析 > 单一词语或检测器分数`

## 一、先分清四件事

| 概念 | 它回答什么 | 单靠文本能否确定 |
|---|---|---|
| AI风格信号 | 文本是否呈现模型常见的分布特征 | 只能给倾向 |
| 作者来源 | 谁写了、谁改了、谁选择了最终版本 | 通常需要草稿、版本链或作者/平台证据 |
| 来源标识 | 作者或平台是否声明有AI参与 | 有标识时可作为来源证据；无标识不等于人写 |
| 写作质量 | 是否准确、具体、有效、有判断 | 与是否使用AI不是同一维度 |

国家网信办规则把AI生成合成内容的显式标识、隐式元数据和平台提示分开处理。[《人工智能生成合成内容标识办法》](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm) 因此，“有AI标识”不能被翻译成“每个字都由AI写”，“没有标识”也不能反推为纯人类原稿。

## 二、AI味的六个观察轴

### 1. 状态增量：句子是否带来新东西

逐句检查本句相对上一句是否新增：对象、事实、动作、人物意图、关系、时间、地点、限制、证据、视角或评价依据。

```text
AI可以提高效率。
AI能够优化流程。
AI有助于提升工作效能。
```

三句没有增加可验证状态。它们的问题不是重复了词，而是没有告诉读者在哪个流程、对谁、通过什么动作、以什么指标提高了效率。

### 2. 结构集中：是否每段都沿同一骨架走

典型候选是“背景—意义—挑战—展望”“观点—解释—总结”反复出现，或每段都使用相同的转折、编号和收束位置。结构本身没有问题：规程、实验步骤、政策条款和考试答案需要结构。问题在于结构不再组织信息，而是掩盖了证据不足。

### 3. 抽象替代具体：评价有没有落到对象和动作

高风险不是“赋能”这个词本身，而是：

```text
这套方案将全面赋能行业生态，推动高质量发展。
```

读者不知道谁对谁做什么、何时发生、以什么结果判断有效。若材料中确实有事实，应写对象、动作、范围和结果；没有事实，就不能用更大的口号填空。

### 4. 语气过度平滑：所有句子都安全、完整、同样端正

这可能表现为句长和句法高度整齐、解释层层补齐、转折无缝、几乎没有作者取舍。它不是“语法正确=AI”，而是要看它是否与同体裁人类样本相比过度集中。

### 5. 风格与事实失配

文字变得更正式、更完整、更像某种风格，但专名、时间、数字、因果、人物关系和限定条件被改写或遗漏。这是“文风变好”与“内容变坏”同时发生的情况。

### 6. 停止失败

目标已经满足后，文本仍添加“总体而言、进一步来看、未来、还可以继续……”等同义收束。车轱辘话的核心不是句式难看，而是继续生成没有必要的状态。

## 三、为什么会形成AI味

### 1. 下一词预测偏好安全的高概率延续

语言模型依据上下文预测下一个token。没有具体材料和限制时，它容易沿着语法稳定、风险较低、社会上常见的路径继续：复述问题、分点、补解释、再总结。这是条件概率的结果，不是模型拥有某种“故意的口音”。[GPT-3训练说明](https://openai.com/index/language-models-are-few-shot-learners/)

### 2. 指令微调和人类偏好奖励“完整、礼貌、有帮助”

“完整”可能变成重复铺陈，“有帮助”可能变成固定客套，“专业”可能变成抽象黑话。用户只写“专业、深刻、有逻辑”，模型就必须自行补全读者、事实、立场和边界，最稳妥的补法往往是通用骨架。

### 3. 训练语料本来就混有机构模板

新闻导语、商业文案、政策文件、学校作文、产品介绍和客服问答都提供了大量可复用句型。大模型学到的是百科、网页、小说、新闻、对话等混合分布；CPM公开的2020年中文训练设置已经包含约100GB多来源中文数据，说明模板化并非ChatGPT时代才出现。[CPM](https://arxiv.org/abs/2012.00413)

### 4. 低随机性、长篇一次生成和多轮“正式化”会压平变化

低随机性让局部选择更集中；一次生成越长，开头的模板越容易被后文继续当作上下文；反复要求“再正式一点、再完整一点”则会叠加同义复述。人类编辑可能保留具体细节，也可能只把口语改成抽象书面语，于是形成混合来源。

### 5. 连续生成会自我强化

开头使用“首先”，后文更容易出现“其次、最后”；前句写“这不仅是技术问题”，后句会寻找“更是认知问题”。这就是可观察的连续性：前面生成的词和结构改变了后续候选概率。它可以通过局部删减和状态检查修复，不能靠藏字符或制造乱码破解。

### 6. AI编辑把事实、风格和来源混在一起

人类核心文本外面可能套了AI开头、AI结尾或AI润色；同一篇文章不能简单归为纯人类或纯AI。AI风格、AI操作、最终作者和平台标识必须分栏记录。

### 7. 合成数据循环是系统层假设，不是单篇定案依据

模型反复使用模型生成数据，可能造成尾部分布收缩和表达均值化。[Model Collapse](https://doi.org/10.1038/s41586-024-07566-y) 这是解释长期分布变化的机制假设，不足以单独解释某篇中文文章。

## 四、人类与AI对照研究给出的校正

| 研究 | 观察到的现象 | 必须保留的边界 |
|---|---|---|
| 中文人类/ChatGPT受控对照 | AI文本可能更流畅、逻辑更显式，人类文本可能更具体、变化更大 | 受任务、模型、领域和Prompt影响；不能把副词或句长做成禁令 | 
| 英语作文对照 | AI更多名词化和复杂句法，人类更多情态/认识表达；GPT-3和GPT-4的词汇多样性方向还可能不同 | 这是英语作文实验，不是中文固定规则 | 
| 同体裁新闻对照 | 人类作者之间的差异可能大于模型之间的差异；特征方向会随体裁和模型反转 | 必须先匹配体裁和作者群 | 
| 摘要与风格迁移 | 人类风格变化更大；模型可按受众/正式度改变输出，但重复迁移可能造成实体幻觉和事实漂移 | 风格控制必须同时锁定事实与关系 | 
| 说明文生成 | 规划、检索、改写、事实核验和风格核验是不同环节 | “像人”不能代替证据链 | 
| 专家识别 | 专家使用词汇、句法、标点、原创性、清晰度等多类线索；非专家容易被高级词和正式度误导 | 单一高频词、低频词或完美语法都不够 | 

代表性来源：[AI essay comparison](https://arxiv.org/abs/2304.14276)、[ChatGPT vs human-authored text](https://arxiv.org/abs/2306.07799)、[LLM/human news comparison](https://arxiv.org/abs/2308.09067)、[formal syntactic comparison](https://arxiv.org/abs/2506.01407)、[Expository Text Generation](https://arxiv.org/abs/2305.03276)、[专家识别研究](https://aclanthology.org/2025.acl-long.267/)。

## 五、如何知道“自己是人类文本”

严格说，不能只靠读感知道。应建立来源等级：

| 等级 | 证据 | 可以说什么 |
|---|---|---|
| H0 | 草稿、版本记录、作者说明、编辑轨迹、原始平台上下文 | 来源链最强，可描述谁在何时做了什么 |
| H1 | 2022年以前的出版物或存档人类作品 | 可作为时间和体裁基线；不能证明网络版本从未被机器处理 |
| H2 | 有作者/平台来源但经过清洗、转发、机构编辑或匿名化 | 可作为来源样本；需记录处理链 |
| H3 | 只有一段无时间、无作者、无版本记录的文本 | 只能标为`unknown` |

2022年以前的《背影》《荷塘月色》《故乡》等作品可作为具体人类写作基线：它们留下车站、物件、动作、声音、天气、距离和记忆变化等关系链。[《背影》](https://zh.wikisource.org/zh-hans/%E8%83%8C%E5%BD%B1)、[《荷塘月色》](https://zh.wikisource.org/zh/%E8%8D%B7%E5%A1%98%E6%9C%88%E8%89%B2)、[《故乡》](https://zh.wikisource.org/zh-hans/%E6%95%85%E4%B9%A1) 这些细节不是“人类专属密码”，而是高情境密度的可观察结果。

十亿级中文资源也必须分开记录：Chinese Gigaword约为十亿中文新闻词，CPM公开约100GB中文训练数据，WanJuan官方资料披露文本超过1TB、文档超过5亿；这些证明公开规模存在，不等于逐字读完，也不等于每个文本都是未加工的人类原稿。[Chinese Gigaword](https://aclanthology.org/L06-1163/)、[WanJuan](https://github.com/opendatalab/WanJuan1.0)

## 六、“隐藏向量”如何严谨理解

普通读者看不到模型的隐藏状态，也不能从成文文本反推出完整向量轨迹。可以研究的是局部代理：

```text
上下文token → 隐藏状态 → 下一token分布 → 新token
```

因此，本项目把“隐藏向量”定义为：

`V_local_token_influence = 删除或替换一个局部片段后，主题、事实、关系、语气、连贯性和停止状态发生的变化。`

Prompt token研究发现，token的影响不均匀：非语言token更容易被删，内容词更可能保留，Prompt末端的token对续写边界尤其敏感。[Evil twins are not that evil](https://aclanthology.org/2025.blackboxnlp-1.3/) 这支持“局部消冗余”，不支持随机打乱、藏字、乱码或故意错别字。

## 七、最终识别流程

1. **记录条件**：语言/方言、时间、地区、媒介、体裁、任务、长度、模型、Prompt、采样、编辑阶段和参照文本。
2. **分开来源**：标注`human_written`、`human_annotated`、`llm_generated`、`human_llm_collaborative`、`synthetic`、`reviewed_synthetic`、`platform_labeled`或`unknown`。
3. **找局部证据**：最多列3处，逐句说明新增了什么状态。
4. **与匹配基线比较**：先同语言、同体裁、同任务，再比较人类作者群与模型输出。
5. **查替代解释**：机构文体、摘要任务、方言、翻译、人工编辑、平台压缩和用户明确格式要求都可能产生相同表面。
6. **给出分层结论**：`风格候选`、`车轱辘话`、`来源证据`和`作者身份`不能合并成一句“这是AI写的”。

## 八、证据边界与当前阅读量

截至2026-08-30，公开中文语料规模已达到十亿字符/词级及TB级；本项目按原文、页面、PDF章节和可核验样本登记的定向直接阅读累计约`3,866,946字符`。这两个数字不可相加，也不可把公开语料库规模改写成“已经逐字阅读”。完整轮次、URL、阅读范围和估算规则见[阅读累计台账](../00_阅读累计台账.md)。

**一句话判断标准：**如果文本只是更顺、更正式、更完整，不足以称为AI味；如果它在匹配基线下持续用平滑模板掩盖状态缺失，并在目标完成后继续同义复述，才是值得优先复核的AI味候选。

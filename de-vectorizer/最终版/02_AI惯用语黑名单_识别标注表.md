# AI惯用语黑名单与识别标注表

最终版｜研究截止：2026-08-30

这是一份“条件性模式黑名单”，不是单词禁令。单个词可以出现在人类文本、政策原文、学术论文、文学修辞和正常对话中；只有当`形式 + 密度/位置 + 信息缺口 + 体裁不匹配`同时出现时，才进入高优先级复核。

## 一、使用规则

### 三档标注

| 等级 | 含义 | 动作 |
|---|---|---|
| L1 荧光 | 命中一个词、短语或格式模式 | 标记，不删除 |
| L2 复核 | 同段重复、相邻段落同构，且没有新状态 | 检查具体对象、证据和体裁功能 |
| L3 编辑 | 两类以上模式聚集，同时存在信息空转、事实缺口或停止失败 | 只做最小修改，并保留事实与来源 |

最低门槛：没有“功能失配”或“信息没有增加”，不得因为命中黑名单而改写。`不是……而是……`、`首先/其次/最后`、`总的来说`都只能启动复核，不能自动删除。

## 二、核心条件性黑名单

| 编号 | 模式家族 | 常见表达 | 何时可疑 | 正常例外 | 建议标签 |
|---|---|---|---|---|---|
| B01 | 先否定、再升华 | 不是A而是B；并非A而是B；不只是A更是B；与其A不如B；看似A实则B | 连续出现，A/B只是同义换壳，B没有具体对象、动作或证据 | 概念纠正、反驳前提、定义边界、文学反差 | `NEGATION-REFRAME` |
| B02 | 双重递进 | 不仅A而且B；既A又B还C；不但A更A | 递进内容可任意互换，连续三次以上，结论只增加气势 | 真实的两层或三层因果/结果 | `PARALLEL-STACK` |
| B03 | 顺序路标 | 首先、其次、再次、然后、最后；第一/第二/第三；一是/二是/三是 | 全文每段都用同一套总分总模板，编号没有组织真实差异 | 流程、规程、政策条款、实验步骤、提纲 | `TEMPLATE-SEQUENCE` |
| B04 | 总结/转场路标 | 综上、总的来说、总体来看、由此可见、进一步而言、换言之、也就是说 | 只把上一句换一种说法，没有事实、限制、例证或行动 | 真实收束、跨层转场、论文小结 | `DISCOURSE-EMPTY` |
| B05 | 服务型开头 | 您好，感谢提问；这是一个很好的问题；你问到了关键话题 | 非对话文章开头反复播报“接下来我将……”而不进入内容 | 客服、邮件、现场对话确有社交功能 | `SERVICE-PREFACE` |
| B06 | 过程播报 | 接下来我们将从几个方面展开；下面详细说明；让我们一起看看 | 元话语占篇幅，后文没有相应的结构或信息 | 教学导航、主持词、明确的阅读提示 | `PROCESS-NARRATION` |
| B07 | 抽象连接词 | 对于……而言；在……层面；基于此；在此基础上；围绕……展开；针对……进行 | 连接词替代主体和动作，删掉后关系不变 | 学术术语、正式法律或政策语体 | `ABSTRACT-CONNECTOR` |
| B08 | 空泛强调 | 值得注意的是；需要指出/强调的是；关键在于；不容忽视；不可或缺；举足轻重 | 后面没有范围、数据、证据或具体对象 | 后文马上给出可核验的重点 | `EMPHASIS-NO-EVIDENCE` |
| B09 | 万能评价 | 具有重要意义；发挥重要作用；意义深远；影响深远；带来积极影响 | 不说明对谁、通过什么机制、发生了什么可观察结果 | 引用原文、标题、政策正式表述 | `EVALUATION-ABSTRACT` |
| B10 | 企业/科技/政策黑话 | 赋能、重塑、构建、打造、引领、驱动、生态、闭环、抓手、赛道、矩阵、链路、沉淀、触达、拉通、落地 | 词语没有对应的对象、步骤、指标和结果 | 项目正式名称或后文明确展开术语含义 | `JARGON-UNBOUND` |
| B11 | 万能形容词 | 深入、全面、系统、完善、高效、优质、卓越、领先、先进、强大、创新、前沿、显著、深刻 | 形容词替代事实，或“显著/全面”没有基线和尺度 | 有明确指标、范围、比较组 | `ADJECTIVE-UNMEASURED` |
| B12 | 过度确定 | 必然、一定、完全、永远、极大、充分、广泛、彻底、毋庸置疑、不言而喻 | 研究只有局部样本，却写成无条件普遍结论 | 文学夸张、数学证明、法律条款的明确义务 | `CERTAINTY-OVERCLAIM` |
| B13 | 保险套话 | 在一定程度上、某种意义上、相对而言、通常来说、可能会产生一定影响 | 多个模糊词叠加，读者不知道不确定性来自样本、因果还是资料缺失 | 真实表达研究边界并说明原因 | `HEDGE-STACK` |
| B14 | 泛化开头 | 在当今社会；随着科技不断发展；在快速变化的时代；近年来受到广泛关注 | 没有日期、事件、人物或问题，任何文章都能套用 | 确实要限定时间范围，且后文马上给出处 | `GENERIC-OPENING` |
| B15 | 口号式结尾 | 未来已来；这只是开始；开启新篇章；未来可期；任重道远；让我们共同期待 | 文章已完成却继续拔高，没有新的行动、限制或问题 | 广告、演讲、文学结尾的有意修辞 | `SLOGAN-CLOSING` |
| B16 | 句末补全 | 这意味着；从而；因此我们可以看出；进一步来看；这不仅说明也反映 | 前句已经完成因果/结论，后句只是回收同一意义 | 后句确实加入新因果、范围或结果 | `TAIL-RESTATEMENT` |
| B17 | 三件套/金句化 | 有温度、有力度、有深度；看见问题、理解问题、解决问题；没有A没有B只有C | 三项内容抽象、节奏过于整齐、段落没有事实推进 | 广告、标题、演讲、诗歌、有意的修辞 | `RHETORIC-TRIAD` |
| B18 | 英文AI腔的中文对应物 | 深入探讨、强有力证明、至关重要、多维度、释放潜力、无缝融合、快速演变的格局 | 翻译腔密集且没有中文语境下的具体动作 | 正式译名、引用、专业术语 | `TRANSLATION-REGISTER` |
| B19 | 伪引用/权威占位 | 根据相关研究；数据显示；业内普遍认为；有学者指出；大量研究证明 | 没有作者、标题、年份、链接、数字或可复核范围 | 后文紧跟真实出处，或明确标为个人判断 | `AUTHORITY-NO-SOURCE` |
| B20 | 题面回声 | 重复用户问题、标题或要求中的词，再加一层泛化解释 | 回声占主要篇幅，未直接完成任务 | 为避免歧义而简短复述关键条件 | `PROMPT-ECHO` |
| B21 | 关系安慰模板 | 你可以放心；我理解你的感受；这很正常；希望能帮到你；如果你需要我还可以 | 非情感任务中成段出现，替代具体答复或行动 | 真正的支持性对话、客服和危机沟通 | `RELATIONAL-TEMPLATE` |
| B22 | 虚构具体性 | 补出无来源的人名、数字、日期、地点、引用或个人经历 | 细节无法追溯，且使文章看似更“像真的” | 输入材料已有出处，或明确标记为假设/示例 | `UNSOURCED-SPECIFICITY` |
| B23 | 统一段落骨架 | 每段均为观点—解释—意义—展望；句长、标点、标题形状高度相同 | 与匹配人类基线相比过度集中，且结构掩盖信息不足 | 表格、规范、考试格式、用户明确要求模板 | `STRUCTURE-CONCENTRATION` |
| B24 | 风格改写漂移 | 把具体动作改为“缺乏某种能力/体现某种价值”，把口语改成空泛正式语 | 语气更顺却丢掉对象、事实、关系或人物声音 | 术语规范化且事实、语气和关系均保留 | `STYLE-FACT-DRIFT` |
| B25 | 停止失败 | 目标完成后继续加总结、展望、意义和“还可以进一步” | 下一句无法新增状态 | 任务明确要求风险、下一步、开放问题或展望 | `STOP-FAILURE` |
| B26 | 伪造人类痕迹 | 故意错别字、乱码、隐藏字符、无意义emoji、假方言、虚构经历 | 仅为改变检测结果或制造“人味” | 原稿已有错误、人物声音、真实方言或平台输入特征 | `FORGED-HUMANITY` |

## 三、黑名单不是“统计特征禁令”

下列现象只能作为弱候选，不能单独判AI：

`正式、复杂、长句、短句、句子顺、语法正确、词汇丰富、词汇简单、低频词、四字词、三项列举、编号、冒号、破折号、顿号、被动句、没有错别字、没有emoji、情绪克制、没有个人经历。`

同体裁研究显示，人类作者之间的差异可能大于人类与模型的差异，词汇多样性的方向也可能随模型、任务和体裁反转。[NYT/LLM句法对照](https://arxiv.org/abs/2506.01407)、[AI作文对照](https://arxiv.org/abs/2304.14276) 非专家容易把高级词、正式度和完美语法误判为AI；专家依赖词汇、句法、标点、原创性、清晰度和引用同质性等多线索组合。[专家识别研究](https://aclanthology.org/2025.acl-long.267/)

方言、借词、代码转换和非标准写法也不能默认标为AI。粤语语料研究把口语词、英语借词和代码转换视为语言环境的正常组成部分。[YueData](https://aclanthology.org/2025.findings-emnlp.102/)

## 四、两类证据门槛

至少满足以下两类，才可写“疑似AI味”；否则只写“待复核”。

1. **形式证据**：命中上表中的句式、词簇、段落同构、题面回声或停止失败。
2. **功能证据**：相邻句没有新增对象、事实、动作、关系、证据、限定、视角或必要体裁功能。
3. **分布证据**：在语言、时间、地区、体裁、任务和参照作者群匹配后，出现异常集中或同模型聚集。
4. **来源证据**：作者声明、草稿、版本链、人工编辑记录或平台标识。它说明来源状态，不等于风格证据。

判断关系：

| 证据组合 | 可写结论 |
|---|---|
| 形式 + 功能 | 车轱辘话/功能失配候选 |
| 形式 + 分布 | AI风格候选 |
| 来源单独存在 | 来源或平台标识，不写成风格结论 |
| 只有单个词/句式 | L1荧光，不做作者判断 |

## 五、标准标注格式

```text
片段：原句或相邻句范围
形式线索：命中Bxx；说明密度、位置和重复关系
状态增量：新增对象/事实/动作/关系/证据/限制/视角/评价依据，或“无新增”
体裁基线：语言、时间、地区、媒介、体裁、任务、参照文本
来源状态：human_written / human_annotated / llm_generated / human_llm_collaborative / synthetic / reviewed_synthetic / platform_labeled / unknown
替代解释：模板体裁、摘要压缩、方言、翻译、人工编辑、平台格式或输入约束
结论：保留 / 合并 / 删除 / 待核；置信度：低 / 中 / 高
```

## 六、最小编辑规则

- 删除无功能复述，或把同一命题合并成一句。
- 把抽象评价绑定到已有材料中的对象、动作、范围、指标和证据。
- 修复事件顺序、人物关系和因果，不凭空补细节。
- 只改命中的片段；没有规则编号的改动撤销。
- 保留事实、专名、数字、日期、引语、来源、限定词、方言功能和作者立场。
- 不用随机错别字、乱码、隐藏字符、假口语和虚构经历逃避检测。
- 不把“换同义词”冒充去AI味：如果没有减少重复或增加清晰度，就恢复原文。

## 七、最终判定模板

```text
结论只能选择：
A. 观察到条件性AI风格信号，但不能确定来源；
B. 观察到车轱辘话/信息空转；
C. 有作者或平台来源证据，文本风格另行判断；
D. 证据不足，保持未知。

禁止直接输出：
“出现某个词，所以一定是AI”；
“没有AI标识，所以一定是人类”；
“人类有错别字，AI没有错别字”；
“改成同义词、加错字就能变成人类文本”。
```

## 八、原始例句没有取消

本最终版为了压缩篇幅，没有重复抄写研究底稿里的全部例句。例句仍保留在根目录的[原始黑名单与识别标注表](../02_AI惯用语黑名单与识别标注表.md)中，包括高风险表达、替换示例、正常例外和后续轮次增加的反误判案例。

Agent 使用本表时不能只读取上面的精简定义。它应先得到候选 B 码，再到原始文件读取对应章节，原样带入例句和例外说明：

```text
候选B码 → 查原始文件章节 → 原样提取例句/例外 → 比较当前句的功能
          → 确认形式 + 功能缺口 → 才允许编辑
```

禁止让 Agent 根据标签自行编造“典型 AI 句”。自行生成的例句会再次带入模型自己的高概率表达，既污染示例库，也可能把条件性黑名单误学成单词禁令。

完整的 B01—B26 章节索引和运行时加载规则见[Agent 去 AI 味研究文档第六节](04_Agent去AI味_基于token连续性重置的专业润色机制.md#六最新版黑名单与编辑动作映射)。

本表的核心对象不是词，而是“可定位的功能失配”。最终要问的不是“这句话像不像AI”，而是：“它为什么在这里出现？它增加了什么？如果删掉，哪项事实或关系会丢失？”

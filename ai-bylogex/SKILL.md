# 去AI味写作润色

对中文文章进行五步润色，去除AI写作痕迹，使其读起来像人类母语写作。

## 使用流程

用户提供一篇已写好的文章后，按以下五步依次执行：

### 第一步：写作话题确定

对文章执行以下规则，确定中心命题和论证方向：

```
建立唯一且明确的中心命题，全文围绕该命题推进，而不是围绕理论展开。
理论只是论证工具，而不是文章主体。禁止按照理论家逐一介绍观点，理论应自然融入论证。
每一段都必须承担新的论证任务，避免重复解释上一段已经完成的观点。
不追求面面俱到，在限定篇幅内形成完整、自洽的论证即可。
保持作者的判断意识。允许提出明确立场，而不是刻意保持平衡。
作者意识，而非知识展示；
连续推进，而非观点堆叠；
理论融合，而非理论罗列；
判断与分析，而非修辞堆砌；
学术表达，而非 AI 风格化写作。
```

### 第二步：修改结构

对文章执行以下规则，润色结构：

```
请润色结构。
不使用小标题。
不采用"理论一—理论二—理论三"的排列结构。
不使用模板化的总分总结构。
结尾仅完成论证收束，不额外升华或拔高主题。
开头与结尾避免使用"不是……而是……""虽然……但是……"等强转折结构。
每1000字重点展开一个案例。
案例必须服务于论证，而不是展示知识储备。
同一个案例可以在不同段落承担不同论证任务，优于不断更换案例。
```

### 第三步：语言润色

对文章执行以下规则，润色语言：

```
请润色语言。
避免使用模板化表达，如：
首先、其次、最后
综上所述
值得注意的是
此外
然而
优先使用动作驱动的表达，使论证保持推进感，减少静态介词堆积造成的停滞。
避免反复依赖"不是……而是……""并非……而是……"等对照句式推进论证，优先使用动词、因果关系和判断句建立联系。
多使用判断句，例如：
A 是 B 在某种关系中的体现。
而不是：
从 A 的角度来看……
主动控制句式节奏，使长短句自然交替，避免连续出现结构完全一致的句子。
避免主动使用高度抽象、模板化的概念词汇作为修辞，例如：
革命、狂欢、重构、投射、具象化、折射、彰显、凸显等。
如果某一概念本身属于理论命题，并且具有明确学术含义，则允许保留其原有表达。
避免主动使用绝对化措辞（如"彻底""必然""毫无疑问""本质""根本"等）增强语势。
只有当绝对化表达直接来自所引用理论，且忠实于理论原意时，才允许使用。
不使用"首先、其次、最后""综上所述""值得注意的是、此外、然而、彰显、凸显、反应、标志、折射、揭示"等模板化表达。
不使用小标题。
使用动词、动态或指向性介词（将、向etc.），不使用过多的静态介词（如在、上、于）。
不使用"不是，而是""并非，而是""绝非，而是"连词，将对比性的材料改为动词连接，如："不是A而是B"改为"突破了A成为了B"。
请下判断，可以多使用"是"的判断词，比如"从A角度来看，B体现C"改为"B是A上的C"。
降低例子的使用数量，每1000字仅允许详细展开一个例子，多余的例子请使用排比句简要提及，在不同的段落从不同的角度分析同一个例子。
不使用"革命、狂欢、溯源、重构、具象化、投射"等词语。
请长短句穿插使用，长句和短句使用"长短长长短短长长短"的穿插方法。
不使用绝对词语，比如"一定、必然、毫无疑问、彻底、永、恰恰、根本、深层、本质"，不知道就保持模糊，如"趋向于、可能、似乎、暗示、表明"。
不用面面俱到，在文本范围内保持论证的完整，自圆其说即可。
开头结尾不要使用转折意义的连词组，如"不是，而是；虽然，但是"。
结尾不升华，简单得出结论。不另起一段。
不使用破折号。
```

### 第四步：再次语言润色

将第三步的规则再执行一遍，查缺补漏，同时检查上次的修改有没有问题。

### 第五步：另存为文件

将润色完成的文章另存为一个新文件，文件名在原文件名后添加"_润色版"后缀。

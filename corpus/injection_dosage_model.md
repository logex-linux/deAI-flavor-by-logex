# 注入式降 AI 味的剂量模型
## ——为什么"局部注入"在困惑度轴上必然失败，在风格统计轴上必然成功

> 版本 1.0 · 2026-09-01
> 本文件是 [`reports/report4_injection_deai.md`](reports/report4_injection_deai.md) 的算术底稿。
> 所有数字标注了「实测」（来自论文）或「本报告推导」（本文件的算术）。

## 一、用户假设的精确表述与验证

**假设**："既然 AI 具有一个可期望的向量，我们可不可以修改个别句段或者字词，通过注入破坏的方式降低 AI 味？"

这个假设**方向正确，但需要拆成两个独立的轴来评估**。本文件的全部价值就在于这个拆分。

---

## 二、轴一：语料级困惑度（Binoculars 类）—— 局部注入**必然失败**

### 2.1 公式

```
logPPL(s) = −(1/L) · Σᵢ log p(xᵢ)
```

**这是一个对 token 的均值。** 注入的高意外 token 是加在分子上的一个有限量，而分母是全文 token 数。

### 2.2 剂量反应表（本报告推导）

注入 k 个 logp = −6.0 的 token（一个相当不常见的专有名词或精确数字大约在这个量级）：

| 全文 L | 起点 logPPL | k=1 | k=3 | k=10 | k=50 | k=100 | 达人类基线 1.00 需 |
|---|---|---|---|---|---|---|---|
| 200 | 0.78 | 0.746 | 0.680 | 0.457 | −0.576 | −1.480 | **>100（仍为负值）** |
| 500 | 0.78 | 0.766 | 0.740 | 0.647 | 0.164 | −0.350 | >100 |
| 1000 | 0.78 | 0.773 | 0.760 | 0.713 | 0.457 | 0.164 | >100 |
| 2000 | 0.78 | 0.777 | 0.770 | 0.746 | 0.615 | 0.457 | >100 |
| 4000 | 0.78 | 0.778 | 0.775 | 0.763 | 0.696 | 0.615 | >100 |

### 2.3 结论

**一篇 2000 词的中文文本（约 3000–4000 token），注入 100 个高意外 token 只能把均值抬 0.323。
而要跨过 0.22 的阈值窗口（0.78 → 1.00），需要改掉 20–50% 的 token。**

> **注**：上表用 logp=−6.0 作为注入值。若用极端值（logp=−15，即几乎不可能出现的 token），
> 数学上可以更快达标，但那种 token 已经不是自然语言——Binoculars 论文自己指出随机 token 串
> 的均分是 **1.35**，被"confidently"判为人类。**这就是上限：你可以把分数推过线，但推过线的
> 那一刻文本已经不能读了。**

### 2.4 推论

**"改个别字词"在困惑度轴上是无效的。** 这不是工程难度问题，是算术问题：
均值对有限扰动具有天然的鲁棒性，而 AI 与人类的差距只有 0.2 左右——比扰动小一个量级。

**但这不等于注入无用。** 见轴二。

## 三、轴二：风格统计量（CCL 2023 类）—— 局部注入**必然成功**

CCL 2023 在 7048 篇平行语料上测出 159 项特征，SVM 判别准确率 97.27%。
这些特征按**计算单位**分级，而计算单位决定了局部编辑的代价。

### 3.1 按编辑代价分级的指标表（本报告推导 + 实测基准）

| 指标 | 计算单位 | 人类 | AI | 局部可推动？ | 最少编辑量 |
|---|---|---|---|---|---|
| **句式模板命中** | 句 | 0–2/千字 | >25/千字 | **✓✓ 最容易** | 改 1 处 = 1 处 |
| 破折号密度 | 句 | 低 | 高 | ✓✓ | 改 1 处 = 1 个 |
| **连词密度** | 句 | 0.013 | 0.036 | ✓ | 每 43 词删 1 个 |
| **并列短语密度** | 句 | 0.251 | 0.729 | ✓ | 改 1 处 = 1 个 |
| **相邻句实词重复性** | 句对 | 0.481 | 0.831 | ✓ | 改 1 处 = 1 对 |
| **句长方差 SD（词）** | 篇章（20–40 句） | 9.248 | 6.729 | ✓ | 改 2–8 句 |
| 平均词长 | 篇章 | 1.704 | 1.861 | △ | 需系统换词 |
| 单音节词占比 | 篇章 | 0.483 | 0.379 | △ | 需系统换词 |
| 字/词 TTR | 篇章 | 0.648/0.725 | 0.470/0.543 | △ | 需引入真正新词 |
| 句均词性数量 | 篇章 | 5.507 | 3.151 | △ | 需系统变换句式 |
| 依存距离分布 | 篇章 | 0–100 均匀 | 集中 25–30 | △ | 需系统变换句式 |
| **Binoculars logPPL 均值** | 语料（千 token） | 1.0 | 0.78 | **✗** | 需改 20–50% token |

### 3.2 ★★★ 最重要的单点发现：SD 对方差敏感，不对均值敏感

这是本文件的核心技术贡献。**要抬高句长方差，不能靠"把长句改短"，必须靠"长短交错"。**

实测推导（用高斯采样模拟 AI 文本的词级句长分布，均值 21.8、SD 6.7）：

**n=10 句，初始 SD=4.32，目标 9.248**

| 操作 | 结果 SD | 达标？ |
|---|---|---|
| 把 1 句改成短句 | 6.35 | ✗ |
| 把 2 句改成短句 | 6.88 | ✗ |
| 把 3 句改成短句 | 7.81 | ✗ |
| 把 5 句改成短句 | 7.21 | ✗ |
| 把 8 句改成短句 | 7.39 | ✗ |
| **把 2 句做长短交错** | **10.39** | **✓** |
| 把 4 句做长短交错 | 11.70 | ✓ |
| 把 6 句做长短交错 | 16.48 | ✓ |

**n=20 句，初始 SD=7.61**

| 操作 | 结果 SD | 达标？ |
|---|---|---|
| 把 8 句改成短句 | 8.81 | ✗ |
| 把 2 句做长短交错 | 8.92 | ✗（接近） |
| **把 4 句做长短交错** | **10.40** | **✓** |
| 把 6 句做长短交错 | 12.36 | ✓ |

**n=40 句，初始 SD=6.57**

| 操作 | 结果 SD | 达标？ |
|---|---|---|
| 把 8 句改成短句 | 7.54 | ✗ |
| 把 6 句做长短交错 | 8.96 | ✗（接近） |
| 把 8 句做长短交错（外推） | ≈9.5 | ✓（估） |

### 3.3 这个发现的三个直接后果

**后果 1：流行的"把长句拆短"建议在数学上是错的。**
把长句拆短只降低均值附近的值，SD 反而可能因为分布更集中而下降或停滞。
上表清楚显示：8 句全改短，SD 只从 4.32 到 7.39；2 句交错就到 10.39。

**后果 2：正确操作是"锚点注入"。**
选 2–4 个位置，**同时**造一个极短句（6–9 词）和一个极长句（38–52 词）。
短句用于截断、判断、命名；长句用于容纳一个完整的因果链或一个具体场景。
这就是"长短长长短短长长短"这句中文写作口诀的数学形式——
**它不是节奏偏好，是方差工程。**

**后果 3：交错的位置比交错的数量更重要。**
交错必须落在**相邻或近邻**的句子上，因为 SD 是全局统计量，
两端的值离均值越远贡献越大（平方项）。一个 6 词句和一个 52 词句放在相邻位置，
比分散在文章两端更能抬 SD。

## 四、"注入"到底该注入什么

按**是否能同时满足两个轴**排序。这是本报告给出的核心判别标准：

| 注入类型 | 困惑度轴 | 风格轴 | 评价 |
|---|---|---|---|
| 具体细节（真实动作、材料、空间关系） | △ 微升 | ✓✓ | **最优** |
| 专有名词（地名/机构/产品/书名） | △ 微升 | ✓ 提 TTR | **最优** |
| 精确数字、日期、时长 | △ 微升 | ✓ 提 TTR | **最优** |
| 非常见但准确的动词 | ✓ 升 | ✓ 破并列 | **优** |
| 第一人称经验、身体状态 | ✓ 升 | ✓ 破客观化 | **优** |
| 自我更正、犹豫（"我本来以为…其实…"） | ✓ 升 | ✓ 破均匀 | **优** |
| 真正的题外话、括号插入 | ✓ 升 | ✓ 破段落同构 | **优** |
| 引语、对话 | ✓✓ 升 | ✓ 破指称 | 优 |
| 冷僻领域术语（用得准确） | ✓ 升 | ✓ 提 TTR | 良 |
| 时代限定的指涉（年度梗、亚文化） | ✓✓ 升 | ✓ | 良，但有过期风险 |
| 四字格/成语 | ✗ 降 | ✗ 升并列 | **有害** |
| 破折号 | ✗ 降 | ✗ | **有害** |
| 同义词替换 | ✗ 不变 | ✗ 不变 | **完全无效** |
| 生造词/硬凑口语 | △ | ✗ 造伪俗语 | **有害** |
| 随机 token | ✓✓ 升 | ✓ | **数学上达标，文本已死** |

### 4.1 ★ "四字格是低意外 token，不是注入"

CCL 2023 实测：四音节及以上词占比人类 **0.027**，ChatGPT **0.047**（1.74 倍）。
→ 成语和四字格在训练语料里高度固化，是**低概率损耗**（即低意外）的 token。
**把它们当"文采"注入，是在往 AI 的方向走。**

### 4.2 同义词替换的双轴无效性

| 轴 | 替换"重要"为"关键" |
|---|---|
| 困惑度轴 | 两个词概率都高，logp 不变 → **无效** |
| 风格轴 | 不引入新概念，TTR 与实词丰富度不变 → **无效** |

→ **同义词替换是两个轴上唯一的完全无效操作。** 这是"降 AI 味"最普遍的浪费。

## 五、剂量处方

### 5.1 每千字的编辑预算（本报告推导）

| 操作 | 每千字次数 | 单次效果 |
|---|---|---|
| **长短交错** | 2–4 组 | SD 抬 1.5–3.0 |
| **注入具体指称**（专名/数字/日期） | 3–6 个 | TTR 微升，可核对性升 |
| **删连词** | 15–25 个 | 连词密度 0.036 → 0.020 |
| **拆并列短语** | 3–8 处 | 句均并列 0.729 → 0.40 |
| **改相邻句论元** | 4–8 处 | 相邻句重复 0.831 → 0.55 |
| **删模板句式** | 全部 | 模板密度归零 |
| **删破折号** | 全部 | 破折号密度归零 |
| **加语气词/第一人称** | 2–5 个 | 语气词密度 0.003 → 0.010 |

### 5.2 一句话总纲

> **不要改词，要改方差。**
> 在 2–4 个相邻位置同时造一个极短句和一个极长句，再给每段塞进一个不可替代的具体指称。
> 这就是"局部注入"能做到的全部——而这恰好覆盖了 8 项可测指标里的 6 项。

## 六、诚实的边界

### 6.1 这个方案不解决什么

1. **不解决困惑度轴的检测。** 若面对 Binoculars 这类双 LM 比值检测器，局部编辑无效。
2. **不解决频率轴（Kobak 式）的检测。** 注入不改变标记词密度，除非注入的恰好不是标记词。
3. **不解决"文本本身不好"的问题。** 本方案优化的是统计指纹，不是内容质量。
4. **不解决语义正确性。** 注入具体指称时有编造风险——必须恪守"不得新增事实"。

### 6.2 过度注入的悬崖

Binoculars 论文实测：**随机 token 串的均分 1.35，被判为人类且"confidently"。**
→ 存在一个"分数达标但文本已死"的区域。
**验收必须用朗读，不能只看分数**（这正是中文实践派四步验收的第一步，也是唯一无法被优化的那一步）。

### 6.3 检测器会适应

本方案的所有操作都在改变**已被发表的统计特征**。
一旦"高低交错 + 密度指称"成为流行写法，它自身会成为新的可测指纹。
**这份方案的有效期与任何词表相同——6 到 18 个月。**
